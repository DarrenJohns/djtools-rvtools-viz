📖 How to export from RVTools:
1. Open RVTools and connect to your vCenter or ESXi host
2. Go to File → Export all to Excel and save as .xlsx
3. Drop the exported file above — include all tabs for maximum analysis depth
Exporting individual tabs (e.g. vInfo only) will still work but with reduced analysis.
